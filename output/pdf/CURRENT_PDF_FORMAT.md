# FTO 1L3T PDF 포맷

이 문서는 현재 확정된 `J / L / Z / S` PDF 레이아웃을 기록한다.
HTML 인쇄 기능은 보류 상태이며, 이 문서는 PDF 생성 규격만 다룬다.

## 출력 파일

- PDF: `fto-1l3t-j-l-z-s-a4-grid.pdf`
- 첫 페이지 미리보기: `fto-1l3t-j-l-z-s-a4-grid-preview.png`

## 데이터 범위와 순서

- 데이터: FTO 1L3T
- 총 케이스: 72개
- 그룹 순서:
  1. `J-even`
  2. `J-odd`
  3. `L-even`
  4. `L-odd`
  5. `Z-even`
  6. `Z-odd`
  7. `S-even`
  8. `S-odd`
- 그룹당 9개 케이스를 한 페이지에 배치한다.
- 전체 페이지 수는 8페이지다.
- 각 카드의 대표 공식은 `algorithms[0]`을 사용한다.

## 페이지 규격

- 용지: A4 세로형
- 페이지 크기: 약 `595.276 × 841.890 pt`
- 좌우 여백: `20 pt`
- 카드 영역 상단: 페이지 상단에서 `42 pt` 아래
- 카드 영역 하단: 페이지 하단에서 `25 pt` 위
- 배치: `3열 × 3행`
- 카드 사이 가로 간격: `7 pt`
- 카드 사이 세로 간격: `7 pt`
- 카드 크기: 약 `180.43 × 253.63 pt`

## 페이지 머리말과 꼬리말

- 왼쪽 머리말: `FTO 1L3T · {그룹명}`
- 오른쪽 머리말: `{현재 페이지} / 8 · J → L → Z → S`
- 머리말 제목 크기: `12 pt`
- 머리말 페이지 정보 크기: `7.5 pt`
- 꼬리말 크기: `6 pt`
- 꼬리말 문구: `swooyi's ALG note · image + setup + representative alg`

## 카드 구성

카드는 위에서 아래 순서로 구성한다.

1. 제목과 recognition 배지
2. 큰 퍼즐 이미지
3. setup 영역
4. 대표 alg 영역

### 제목

- 형식: `[{그룹명}] {케이스명}`
- 글자 크기: `8.5 pt`
- recognition 배지 글자 크기: `5.4 pt`
- 그룹별 강조색을 카드 왼쪽 선과 배지에 사용한다.

### 퍼즐 이미지

- 카드 안쪽 좌우 여백: `8 pt`
- 이미지 박스 높이: `121 pt`
- 이미지 박스 내부 좌우 여백: `16 pt`
- 이미지 박스 내부 상하 여백: `8 pt`
- SVG의 원래 비율을 유지하면서 가능한 크게 맞춘다.

### setup

- 이미지 아래 간격: `5 pt`
- 영역 높이: `42 pt`
- 제목 크기: `5.2 pt`
- 본문 크기: `5.5 pt`
- 긴 setup은 단어 단위로 자동 줄바꿈한다.

### 대표 alg

- setup 아래 간격: `5 pt`
- 카드 하단 안쪽 여백: `8 pt`
- 제목 크기: `5.2 pt`
- 본문 크기: `5.7 pt`
- 긴 공식과 주석은 원래 줄바꿈을 유지하면서 추가로 자동 줄바꿈한다.

## 글꼴

- 글꼴: Pretendard Variable
- 제목과 본문은 PDF에 글꼴을 포함해 출력한다.
- setup과 공식은 작은 크기에서도 읽히도록 굵은 본문을 사용한다.

## 데이터 원본

- 케이스: `alg/fto/1l3t/cases.json`
- 그룹과 페이지 순서: `alg/fto/1l3t/groups.json`
- 퍼즐 이미지: `alg/fto/1l3t/svgs.json`

## 검증 기준

- PDF가 A4 세로형 8페이지인지 확인한다.
- 페이지마다 카드가 정확히 9개인지 확인한다.
- 각 페이지에 해당 even 또는 odd 그룹만 포함되는지 확인한다.
- 72개 케이스가 모두 존재하고 중복이나 누락이 없는지 확인한다.
- 모든 페이지를 PNG로 렌더링해 이미지, setup, 대표 alg가 잘리거나 겹치지 않는지 확인한다.
