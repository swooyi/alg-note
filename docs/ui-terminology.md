# UI 구성요소 용어 정리

이 문서는 alg-note 프로젝트 요구사항을 말할 때 화면 구성요소를 일관되게 지칭하기 위한 용어 정리다.

## 기본 원칙

- HTML 태그명보다 화면에서 보이는 영역 이름, 위치, 역할을 기준으로 말한다.
- 특정 기능 요청은 `화면 이름 > 영역 이름 > 요소 이름 > 원하는 동작` 순서로 말하면 가장 명확하다.
- 버튼, 토글, 표시부, 패널처럼 UI 역할이 드러나는 단어를 붙인다.

## 권장 용어

| 용어 | 의미 |
| --- | --- |
| 상단바 / 헤더 | 페이지 맨 위의 제목, 탭, 전역 버튼이 있는 영역 |
| 탭바 / 모드 탭 | `FTO`, `3x3`, `드릴`, `노트`처럼 화면 모드를 바꾸는 버튼 묶음 |
| 드릴 화면 | 알고리즘을 보고 외우거나 훈련하는 메인 화면 |
| 드릴 컨트롤바 | `Recap`, `Train` 같은 드릴 실행 버튼들이 모인 줄 |
| Recap 버튼 | 복습 모드 시작 또는 전환 버튼 |
| Train 버튼 | 훈련 모드 시작 또는 전환 버튼 |
| 랜덤 AUF 토글 | AUF를 랜덤으로 추가할지 켜고 끄는 on/off 옵션 |
| 문제 카드 / 케이스 카드 | 현재 연습할 케이스, 이름, 이미지, 알고리즘이 표시되는 중심 영역 |
| 케이스 상세 모달 / 상세 모달 | 문제 카드나 케이스 카드를 눌렀을 때 뜨는 플로팅 세부사항 창 |
| 케이스 이미지 / 퍼즐 뷰 | FTO나 3x3 상태 그림이 나오는 부분 |
| 알고리즘 표시줄 | `setup`, `alg`, `solution` 같은 수식 또는 회전 문자열이 보이는 부분 |
| setup 표시부 | 알고리즘 앞뒤에 붙는 setup move가 표시되는 곳 |
| 타이머 영역 | 시간 숫자가 크게 표시되는 부분 |
| 타이머 숫자 | 실제 시간 텍스트 |
| 결과 / 기록 패널 | solve 기록, 평균, 성공/실패 같은 결과가 쌓이는 영역 |
| 필터 패널 | 케이스 종류, 세트, 난이도 등을 고르는 영역 |
| 설정 패널 / 옵션 패널 | 토글, 체크박스, 표시 옵션들이 모인 영역 |

## 요구사항 작성 예시

### 랜덤 AUF 기능

드릴 화면의 드릴 컨트롤바에서 `Recap` / `Train` 버튼 옆에 랜덤 AUF 토글을 추가한다.

- 토글 ON이면 FTO는 setup 앞 또는 뒤에 `U` / `U'`를 랜덤 삽입한다.
- 토글 ON이면 3x3은 setup 앞 또는 뒤에 `U` / `U'` / `U2`를 랜덤 삽입한다.
- 토글 OFF이면 기존 setup 표시와 동작을 유지한다.

### 타이머 숫자 폰트

타이머 영역의 타이머 숫자 폰트가 가로로 넓어 보이므로 더 좁은 숫자 폰트나 폭 조정이 필요하다.

## 추천 표현 형식

```text
[화면 이름]의 [영역 이름]에서 [요소 이름]을/를 [원하는 동작]하도록 수정.
```

예:

```text
드릴 화면의 드릴 컨트롤바에서 Recap/Train 버튼 옆에 랜덤 AUF 토글을 추가.
```
