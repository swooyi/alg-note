# ALG note 이미지 · 시뮬레이터

이 폴더에는 FTO, 3×3, Square-1 이미지 생성기와 시뮬레이터의 실행 파일 및 원본 소스가 들어 있습니다. `C:\dev\FTO Image generator` 폴더가 없어도 동작합니다.

ALG note 홈 화면의 제목 아이콘을 누르면 이 폴더의 첫 화면이 열립니다. alg 세트를 선택하면 그림이 표시된 케이스 선택 창이 열립니다. 케이스 세부 화면의 **이미지 · 시뮬레이터**를 눌러 바로 들어갈 수도 있습니다. 편집 화면에서 다른 케이스를 그림으로 선택하거나 이전·다음 케이스로 이동할 수 있습니다. 상단의 setup 또는 ALG를 눌러 회전기호를 불러오고, 원하는 보기의 **이미지 반영**을 누르면 그 케이스의 이미지가 바뀝니다. 별도 이미지 업로드와 기존 이미지 복원도 지원합니다. 이미지는 브라우저의 IndexedDB에 케이스별로 저장됩니다.

이미지 반영 시 그림 SVG와 복원 설정을 분리해 보관합니다. `cases.json`에는 `imageState: { view, settings }`만 저장하고, SVG는 `svgs.json`의 기존 `svgId` 키에 저장합니다. 생성기에서 케이스를 열면 `settings`의 색 배치와 시점을 복원합니다. 별도 업로드 이미지와 예전 SVG만 있는 브라우저 기록은 복원 설정 없이 그림만 반영합니다. 예전 `imageState.svg` 기록도 읽을 수 있지만 다시 출력하면 그림과 설정을 분리합니다.

ALG note의 수정 JSON은 모든 세트에서 현재 원본과 차이가 나는 공식·setup·인식 태그·메모 편집분만 출력합니다. `imageState`와 SVG는 내보내지 않으며, 브라우저의 이미지 반영은 IndexedDB에 저장됩니다. 수정 JSON의 `cases`를 해당 원본 cases.json에 병합한 뒤 `scripts/build_app_data.py`로 웹 데이터를 재생성합니다. TCP 케이스는 공유 원본인 FTO 1L3T에 반영합니다.

원본 JavaScript를 바꾼 뒤에는 이 폴더에서 `npm run build`를 실행해 정적 번들을 다시 만듭니다. 생성기 고유 기능은 각 페이지에서 그대로 사용할 수 있습니다.

FTO 케이스의 세부 모달에서는 각 ALG 왼쪽의 ▶ 버튼으로 내장 시뮬레이터를 엽니다. case의 setup에서 시작해 선택한 ALG를 재생하며, 저장된 색 배치·스티커 마킹·이미지 관찰 시점을 적용합니다. 재생/일시정지, 처음/이전/다음/끝, 속도, 드래그 관찰, 확대, 시점 초기화, 마킹 및 회전면 기호 표시를 지원합니다. 마킹이 없으면 해당 토글은 비활성화됩니다. 회전기호 창은 원문을 유지하며 EIF 구간과 현재 회전을 표시합니다. `[U]` 그룹, `[A:B]` conjugate, `[A,B]` commutator를 지원하고 해석할 수 없는 표기는 재생 대신 오류를 표시합니다. 생성기 편집 기능과 분리되어 원본 데이터나 브라우저 이미지 기록을 바꾸지 않습니다.

`case-player-fto.html`은 빌드 시 기존 FTO 페이지에서 생성하며, 앱 데이터 번들과 편집 연동 스크립트를 중복 로딩하지 않습니다.

세부 모달을 열면 플레이어 엔진을 미리 준비하고, 이후 ALG를 바꿀 때 같은 엔진을 재사용합니다. 닫을 때는 재생과 진행 중 회전을 중지합니다. 케이스를 불러올 때는 3D 표시에 필요한 색·마킹·시점만 적용하며 숨겨진 이미지 편집 화면을 다시 렌더링하지 않습니다.

HTML 파일 직접 열기(`file:`)와 HTTP 접속을 모두 지원합니다. 파일 직접 열기의 메시지 출처는 `null`로 검사하며, 실제 메시지를 보낸 창이 준비된 플레이어/부모 창인지도 확인합니다.
